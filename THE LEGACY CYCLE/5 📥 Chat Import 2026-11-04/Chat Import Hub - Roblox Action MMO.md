## How this fits The Legacy Cycle
The chat began without the Legacy Cycle notes, so some parts overlap and some conflict. The team needs to decide which parts to adopt.

| Topic | This chat's plan | Legacy Cycle plan ([[Project Plan Overview]]) | Fit |
| --- | --- | --- | --- |
| Genre | Anime-style action MMO, hack-and-slash | Dark-fantasy open-world action RPG | Overlap: both combat-first |
| Setting and story | "Shattered Sky": floating islands, the Hush (fog that erases memory), the Wakeling | The Cycle, the Void, the Ember, Havenbrook ([[Story Foundation]]) | **Conflict: pick one** |
| Power system | Echoes (spirits of forgotten things) plus weapon styles | Ember plus weapons and skills, legacy traits ([[Legacy System Spec]]) | **Conflict**, but the ideas can merge (see below) |
| Boss memories | Each Echo or boss reveals a memory | Each boss leaves a memory of how they fell | Same idea in both |
| Team | 4 roles (A combat/lead, B world/story, C art/motion, D UI/audio/community) | 5 roles ([[Team and Roles]]) | Reconcile |
| Monetization | Cosmetics plus a battle pass per chapter, never power | Cosmetics only, no premium currency ([[Economy and Monetization]]) | Compatible; the battle pass is new |
| Reasons to come back | A new story chapter and battle pass every 6 weeks, daily missions | Listed as **missing** in [[GDD v0.2 Review]] | This chat's plan fills that gap |
| Platforms | Mobile-first rules (80% of players are on mobile), 8 buttons max | Parry over mobile ping noted | Compatible |
| Tools | Rojo + git from the start | Team Create first, Rojo later | Compatible |
| Roadmap | 6 phases with gates; launch target late June 2027 | Milestones A–E | Compatible; map phases onto milestones |

**Possible merge** (a suggestion, not a decision): keep the Legacy Cycle story and use parts of this plan around it. Echoes could become the **memories of fallen heroes** carried in the Ember. Each region boss you defeat gives a move set and a memory. Drafted in full in [[Merge Proposal - Legacy Cycle and Action MMO]]. That keeps the Legacy Cycle story and adds the "every power tells part of the story" hook. The 6-week chapter cadence, battle pass, mobile rules, team task sheet and roadmap gates work with either story.
